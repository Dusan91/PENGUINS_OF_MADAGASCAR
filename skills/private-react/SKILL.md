## What I do

- Implement React/Next.js components following existing project conventions
- Use functional components only (no class components)
- Reuse existing components and hooks from the codebase
- Follow existing file structure and naming conventions
- Respect Next.js client/server boundaries ('use client' / server components)

## When to use me

Apply this skill whenever implementing React or Next.js component code.

## Constraints

- Do NOT introduce new libraries without Skipper approval
- Do NOT refactor existing components unless explicitly instructed
- Do NOT change API shapes or contracts
- Deviations must be approved by Skipper
