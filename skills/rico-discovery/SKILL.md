## What I do

- Identify Next.js router type (App Router or Pages Router)
- Locate UI component libraries and design system components
- Identify styling conventions (Tailwind, CSS Modules, styled-components, etc.)
- Detect state management patterns (Jotai, Zustand, Redux, Legend-State, etc.)
- Detect data fetching patterns (react-query, SWR, server components, etc.)
- Identify naming conventions (files, components, hooks, utils)
- Surface constraints and protected areas

## When to use me

Use this skill when you need to explore the codebase before planning or implementing anything.
Always run discovery before analysis.

## Restrictions

- DO NOT modify any code
- DO NOT propose solutions
- Only report facts: paths, snippets, patterns, gotchas
